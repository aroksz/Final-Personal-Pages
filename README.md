# School Helper - Moses Yang

A student-designed interactive website based on Moses Yang's original hand-drawn sketch.

## Included features
- A+ paper profile logo
- School Helper title with ruler and apple decoration
- Practice Quiz
- Flashcards
- Homework Tracker (saved in the browser with localStorage)
- Study Timer
- School Helper Chatbot
- Interactive Knowledge Book
- Responsive design for computers, tablets, and phones

## Files
- `index.html` - page structure
- `style.css` - visual design
- `script.js` - all interactive behavior
- `assets/school-helper-logo.svg` - logo
- `Moses_Yang_Original_Sketch.jpg` - original student design
- `School_Helper_GitHub_Publishing_Instructions.docx` - publishing guide

## Test locally
Double-click `index.html` to open the website in a browser.

## Publish
Follow the included Word document to publish the site with GitHub Pages.
